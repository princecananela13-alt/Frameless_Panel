# Frameless Panel (overlay app for Frameless_AI v1.3.0)

Build (pick one):
1. GitHub: upload this folder to a new repo -> Actions -> "Build APK" -> download artifact `FramelessPanel.apk`.
2. Android Studio: open folder, Build > Build APK(s).

Install:
- Install FramelessPanel.apk (or save it as /sdcard/Download/FramelessPanel.apk before flashing the module; it installs at boot).
- Flash Frameless_AI v1.3.0, reboot.
- WebUI > Games > In-game panel: ON. Add your games in "My games".
- Open a listed game: handle appears on the screen edge. Swipe it inward (or tap) to open the panel. Leave the game: it disappears.
- "Preview panel now" in the WebUI shows it without opening a game.
